# 🌃🥁 NEON//BEAT

**Single-page modular synth and loop-studio interface with sequencing, drum tracks, project controls, sound browsing, and audio-export workflows.**

🏷️ Maintained in [qamotech/n8loops](https://github.com/qamotech/n8loops) · 🌐 Public repository

## ✨ What is here

- 🥁 Sequencer tracks, pattern banks, swing-oriented and generative controls.
- 🎹 Sound browser, preview, arpeggiation, and performance controls.
- 💾 Project-library, JSON import/export, and session controls.
- 🎧 Mixer, spatial controls, WAV/stem export interfaces, and quick guide.

## 🧭 Try the project

Start audio from a click, preview a sound, add a short pattern, save a project, and audition an export at a comfortable volume.

## 🚀 Local setup

```sh
git clone https://github.com/qamotech/n8loops.git
cd n8loops
```

Use a current browser. Serve the repository root to preserve relative assets and a stable browser origin:

```sh
python -m http.server 8000
```

Open `http://localhost:8000/index.html`. Keep related assets beside the entry file. No npm setup is declared in the inspected repository.

## ⚙️ Configuration & data

The interface includes latency, limiter, and spatial-audio claims that have not been independently measured in this pass. Some controls may be experimental; verify exported files and audible results before relying on them.

Keep credentials, private exports, customer records, and personal information out of commits and screenshots. A local browser demo is not evidence of account security, reliable persistence, or connected external services. Preserve exports before changing storage keys or resetting an application.
